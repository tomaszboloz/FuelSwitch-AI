# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of FuelSwitch AI seriously. All credentials and OAuth tokens are stored locally on your machine with strict POSIX permissions (`0600`) and are never dispatched to any external telemetry server.

If you discover a security vulnerability within FuelSwitch AI, please do **NOT** open a public issue.

Instead, please send an advisory report to Tomasz Bołoz via **[https://www.damtox.pl](https://www.damtox.pl)**.

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue or a proof-of-concept.
- Affected versions and environments.

You will receive an acknowledgement within 48 hours, followed by updates on remediation and coordinated disclosure.
